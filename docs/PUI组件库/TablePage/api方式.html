api方式使用 ​

html

<!-- 简单使用 -->
<PuiTablePage :api="axiosObject"  :columns="columns" /> 

<!-- 常规使用 -->
<PuiTablePage  :api="axiosObject" :apiParams="apiParams" :columns="columns" :optBtns="optBtns" @optBtnClick="optBtnClick" >
    <template v-slot:tree> 树结构布局插槽 </template>
    <template v-slot:search> 查询插槽 结合 PuiSearch使用 </template>
    <template v-slot:***> 单元格插槽，columns中声明*** </template>
</PuiTablePage>

<!-- 完整使用 -->
<PuiTablePage  :api="axiosObject" :apiParams="apiParams" :columns="columns" :optBtns="optBtns" apiResShim="res.data" :apiResSuccess="apiResSuccess" :pageShim="{ pageNo: 'currentPage', pageSize: 'size' }" 
    @select="onSelect" @select-all="onSelect" @optBtnClick="optBtnClick">
    <template v-slot:tree> 树结构布局插槽 </template>
    <template v-slot:search> 查询插槽 结合 PuiSearch使用 </template>
    <template v-slot:***> 单元格插槽，columns中声明*** </template>
</PuiTablePage>

通用配置 ​

属性值默认值描述
hasPageBooleantrue是否需要分页逻辑
optBtnsArray[]表格上方的权限按钮组 eg:[{opt:'add', permission:'use:add'}]

tableData方式 （外部请求数据） ​

属性值类型默认值描述是否必传
columnsObject-Array[]表格列声明的对象数组是
totalNumber接口返回时的总条数, 只在传入tableData下有效是
hasPageBooleantrue是否需要分页逻辑否

api 方式(内部请求数) ​

属性值默认值描述是否必传
apiaxios-ObjectAxiosObjectaxios接口对象,自动请求接口获取数据是
totalShimString'res.data.total'接口返回时的总条数, 只在api模式下有效否
pageShimObject{ pageNo: null, pageSize: null }分页垫片，分页的参数名不是默认值时，自己声明分页参数名否
apiParamsObject接口请求的参数，可将puiSearch的值放入作为查询参数；不需要分页参数不需要传，内部有维护 【如果不希望初始化就调用接口，可默认api为空，在apiParams处理好后再给api赋值】否
apiResShimString'res.data.list'表格数据使用 接口返回的那部分数据； 总条数模式使用res.data.total如不一致请联系开发者否
apiResSuccessFuntion自己处理接口返回的数据，return list给内部的表格使用否
hasPageBooleantrue是否需要分页逻辑否

事件 完整示例代码 ​

事件名返回值说明
select[]选中的行，选择行时触发
select-all[]选中的行，全选或取消权限时触发
select-chage/selection-change/select-change[]选中的行，选中行改变时触发
cell-click{}单元格点击时触发
optBtnClick{'add', selectedRows}点击optBtns配置的按钮时触发, 返回按钮的操作类型、表格当前选中行

插槽名参数描述
